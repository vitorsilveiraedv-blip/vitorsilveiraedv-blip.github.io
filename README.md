# Vitor Silveira — AI Response Evaluation Portfolio

A responsive, dependency-free static portfolio in English and Brazilian Portuguese. Use `index.html` for English and `index-pt.html` for Portuguese. Each page links to the other in the navigation. Case study content is written directly in semantic HTML so it can be reviewed and updated without a build step.

## Run and preview

Open `index.html` or `index-pt.html` in a browser, or serve the `outputs` folder with any static file server. For example, with Python installed:

```sh
python -m http.server 8000 --directory outputs
```

Then visit `http://localhost:8000`.

## Publish

Upload the contents of this folder to a static host such as GitHub Pages, Netlify, or Cloudflare Pages. No server-side code or build command is required. Configure the host to use this folder as the site root.
